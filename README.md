# Enterprise Network Design & Security Simulation

## Description
Designed and implemented a secure enterprise network for a medium-sized organization using **Cisco Packet Tracer**. The project simulates a real-world business network by incorporating VLAN segmentation, inter-VLAN routing, subnetting, wireless networking, DHCP, DNS, and Access Control Lists (ACLs). 

The network was designed with a focus on **security, scalability, and efficient communication** between departments while enforcing controlled access through strict routing and security policies.

---

## 🚀 Features
* **Topology Design:** Realistic enterprise network topology blueprint.
* **Network Segmentation:** VLAN implementation for strict departmental isolation.
* **Routing & Addressing:** Custom IPv4 subnetting schemas and Inter-VLAN routing.
* **Automated Services:** Dynamic Host Configuration Protocol (DHCP) and Domain Name System (DNS) server configuration.
* **Hardware Config:** Comprehensive configuration of Routers, Layer 2 switches, and Layer 3 switches.
* **Wireless Networks:** Wireless Access Point deployments featuring WPA2/WPA3 enterprise security.
* **Traffic Control:** Access Control Lists (ACLs) to filter unauthorized traffic.
* **Testing & Validation:** Dynamic end-to-end connectivity verification and edge-to-edge internet simulation.

---

## 🛠️ Technologies Used
* **Simulation Tool:** Cisco Packet Tracer (v8.x+)
* **Routing & Switching:** Inter-VLAN Routing, Static Routing, Layer 2/3 Switching, VLANs
* **Network Services:** DHCP, DNS, IPv4 Subnetting
* **Security & Wireless:** Access Control Lists (ACLs), WPA2/WPA3 Security Protocols

## 📦 Installation & Setup

### Requirements
* **Cisco Packet Tracer 8.x** or later installed on your machine.

### Launch Instructions
1. Download or clone this repository to your local system.
2. Launch **Cisco Packet Tracer**.
3. Go to **File > Open** and select the included network topology file (`.pkt`).

---

## 💻 Usage & Verification Guide
1. **Topology Walkthrough:** Open the file to explore the structured enterprise layout.
2. **Configuration Audit:** Review the CLI configurations for the routers, L2/L3 switches, and security policies.
3. **Automated Services Check:** Boot the network endpoints to verify automated DHCP address allocation and DNS resolution.
4. **Traffic Simulation:** Use the standard Packet Tracer `ping` tool or **Simulation Mode** to track packet paths between departments.
5. **Security Policy Testing:** Attempt communication between restricted networks to observe ACL blocks and firewall behavior.
6. **Documentation Reference:** Refer to the included comprehensive project report for design schemas, implementation steps, and precise testing benchmarks.
